## Como executar
1. Carregue o arquivo ```.pl``` em um interpretador Prolog compatível.
2. Execute o predicado ```?- menu.``` para iniciar o sistema.
3. Selecione uma das opções apresentadas no menu.

## Observações
### Execução no SWISH
Ao executar o sistema no SWISH (interpretador online de Prolog), o predicado utilizado para pausar a execução pode apresentar comportamento diferente do interpretador local.

Quando a mensagem abaixo for exibida: 

```Pressione Enter para continuar...```.

digite qualquer valor (por exemplo, 0) e então pressione <b>Enter</b> para prosseguir.
